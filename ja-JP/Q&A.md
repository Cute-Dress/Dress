なぜ？？？
--------------

簡単に言うと、コードを書かずに、より多くの人に GitHub の理念を学び、理解してもらいたいからです。  

プログラマーではない人も、プロジェクトに協力する必要があることは少なくありません。ここではプログラミングスキルがなくても参加できるので、彼らにとって練習にぴったりだと思います。

GitHub のリソースを大量に消費しますか？
---------------

いいえ。

PR をマージする前に、写真が全部圧縮されたかを確認します。1MB を超えた写真や基準を満たさない写真は受け付けません。これは GitHub ワークフローのトレーニングにもなると思います。

将来的には、リポジトリの可用性を保つために、孤立オブジェクトを定期的に整理することもあります。

本当に役に立ちますか？
---------------

はい、そう考えています。

このプロジェクトはすでに GitHub への関心を集め、多くの人に「GitHub の理念とワークフロー」と「GitHub の簡単な使い方」をわかりやすく伝えてきました。

また、議論に参加して、フォーク、ブランチのマージ、リポジトリサイズの管理、リポジトリのメンテナンスといった問題を解決することを通じて、ユーザーのチームワーク能力も育ててきました。
