なぜ？？？
--------------

簡単に言うと、コードを書かずに、より多くの人に GitHub の理念を学び、理解してもらいたいからです。  

プログラマーではないけど、プロジェクトのメンテナンスに協力しないといけない人もいます。ここではプログラミングスキルがなくても参加できるので、彼らにとって練習にぴったりだと思います。

GitHub のリソースを大量に消費しますか？
---------------

いいえ。

PR をマージする前に、画像が全部圧縮されたかを確認しますので、1MB を超えた写真や基準を満たさない写真は受け付けません。これは GitHub ワークフローのトレーニングにもなります。

将来的には、リポジトリの可用性を保つために、孤立オブジェクトを定期的に整理するかもしれません。

本当に役に立ちますか？
---------------

はい、そう考えています。

このプロジェクトはすでに GitHub への関心を集め、多くの人に「GitHub の理念とワークフロー」と「GitHub の簡単な使い方」をわかりやすく伝えてきました。

また、議論に参加し、フォーク、ブランチのマージ、リポジトリサイズの管理、リポジトリのメンテナンスといった問題を解決することを通じて、ユーザーのチーム協働力も育ててきました。
