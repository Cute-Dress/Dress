# 部分クローンガイド

Dress リポジトリには大量の画像が含まれています。`--depth 1` だけを使うと古いコミットは省略されますが、現在のバージョンに含まれるすべての画像は依然としてダウンロードされます。自分のディレクトリだけを変更する予定なら、部分クローンとスパースチェックアウトを併用することをおすすめします。Git はまずコミットとディレクトリ構造をダウンロードし、選択したディレクトリをチェックアウトするときにだけ、その中のファイルを必要に応じてダウンロードします。

> Git 2.25 以上が必要です。`git --version` でバージョンを確認できます。

## 初回クローン

まず GitHub 上で本リポジトリを Fork し、自分の Fork をクローンします。コマンド内のユーザー名とディレクトリは実際の値に置き換えてください：

```bash
git clone --filter=blob:none --sparse --depth 1 https://github.com/<ユーザー名>/Dress.git
cd Dress

# 自分のディレクトリだけをチェックアウト。リモートにまだそのディレクトリがなくても、先に設定できる
git sparse-checkout set '<頭文字>/<フォルダ名>'
```

たとえば `N/Nano` を使う場合：

```bash
git sparse-checkout set 'N/Nano'
```

このときワークスペースにはルートディレクトリのドキュメントと `N/Nano` が含まれ、他のコントリビューターの画像は表示されません。フォルダ名が数字や記号で始まる場合は `#` ディレクトリを使い、パスを必ず引用符で囲んでください：

```bash
git sparse-checkout set '#/233'
```

あとはディレクトリを作成し、写真を追加して、通常どおり `git add`、`git commit`、`git push` を使えます。完全なコントリビューション手順は [ガイド](GUIDE.md) を続けてお読みください。

## チェックアウトするディレクトリの管理

現在選択しているディレクトリを確認：

```bash
git sparse-checkout list
```

既存のディレクトリを残したまま別のディレクトリを追加：

```bash
git sparse-checkout add 'A/AnotherName'
```

ディレクトリを選び直す場合、`set` は以前のディレクトリリストを置き換えます：

```bash
git sparse-checkout set 'F/FirstName' 'S/SecondName'
```

Git は必要に応じて新しく選択したディレクトリ内のファイルを自動でダウンロードするため、ディレクトリが小さいほどダウンロード量とディスク使用量は通常少なくなります。

## さらに多くの履歴を取得する

`--depth 1` は最新のコミットだけを含む浅いクローンを作成します。通常の写真追加や PR 作成には影響しません。完全な履歴を確認したい場合は、次を実行します：

```bash
git fetch --unshallow
```

これで完全なコミット履歴を取得できますが、画像の内容は引き続き部分クローンによって必要に応じてダウンロードされます。

## リポジトリ全体を復元する

現在のバージョンのすべてのファイルをワークスペースに表示したいだけなら、スパースチェックアウトを無効にします：

```bash
git sparse-checkout disable
```

このコマンドは現在のバージョンでまだ取得していないファイルをダウンロードするため、データ量が大きくなる可能性があります。リポジトリには部分クローンの設定が残るため、古いバージョンのファイルは引き続き必要に応じてダウンロードされます。

すべての履歴とファイル内容を含む完全なクローンに本当に変換する必要がある場合は、続けて次を実行します：

```bash
git fetch --unshallow --no-filter
git config --unset remote.origin.partialclonefilter
git config --unset remote.origin.promisor
```

以前に `git fetch --unshallow` を実行済みの場合、再度実行するとリポジトリが浅いクローンではないと表示されます。その場合は `git fetch --no-filter` に置き換えてください。

## よくある質問

### なぜルートディレクトリのドキュメントが表示されるの？

`git clone --sparse` はデフォルトでコーンモードを使用します。このモードではリポジトリのルートディレクトリのファイルが保持されるため、`README.md` や `GUIDE.md` などの説明ドキュメントを直接読めます。

### なぜ選択したばかりのディレクトリが表示されないの？

まず `git sparse-checkout list` を実行して、パス、大文字小文字、頭文字ディレクトリを確認してください。リモートに存在しない新しいディレクトリは自動では表示されません。作成してファイルを追加したあとに初めてワークスペースに表示されます。

### 部分クローンはコミットや PR に影響する？

いいえ。チェックアウトされていないファイルは引き続き Git によって管理され、`git add` や自分のディレクトリのコミットによって削除されることはありません。自分のディレクトリだけを変更し、コミット前に `git status` で変更内容を確認してください。
