### フォルダの命名規則とファイル標準

- 画像の盗用および他人の画像の無断転載はお断り
- フォルダ名は意味のある名前にしてください
- GitHub ID や SNSのニックネームのローマ字はおすすめ
- フォルダは頭文字ごとに分類してください
- フォルダー名にはブランクを入力しないようにしてください
- 並び順に影響するフォルダ名（例：`AAAA.Folder`、`0.Folder`、`111Folder`）を含む PR はクローズされます
- フォルダ内に README などの説明ファイルを作成する場合は、[Markdown](https://en.wikipedia.org/wiki/Markdown) 記法で記述してください
- 画像はできるだけ圧縮して（1 MB 以下）、[EXIF の説明](EXIF.md) に従ってセンシティブな情報を削除してください（削除方法は [コントリビューションの準備](CONTRIBUTING.md) を参照）。画質が低すぎる画像を含む PR はクローズされます
