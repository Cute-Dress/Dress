## 写真の基準

- 画像の盗用および無断転載はお断り
- 可愛いは正義
- 性別不問

### プライバシーにご注意

写真には EXIF データが含まれていることがあり、撮影場所や撮影機材などの情報が記録されています。意図しない個人情報の漏えいに注意し、写真を push する前に写真内の EXIF 情報を適切に処理してください。

本プロジェクトは GPS・住所・連絡先などのセンシティブなメタデータを自動的にブロックします。具体的なフィールド範囲とセンシティブレベルは [EXIF](EXIF.md) をご覧ください。

削除方法はこちら：

> 1. [GIMP](https://www.gimp.org/downloads/)で：GIMP を開いて、処理したい画像を読み込みます。「ファイル」>「名前を付けてエクスポート」（Export As）を選び、「画像をエクスポート」ダイアログに `new_image.jpg` のように JPEG 拡張子のファイル名を入力して「エクスポート」ボタンをクリックします。続いて開く JPEG のエクスポートオプション画面で、「Advanced Options（詳細）」内の「Save EXIF data」のチェックを外し、もう一度「エクスポート」をクリックすると、EXIF 情報を削除した画像が保存されます。
> 
> 2. [ExifTool](https://exiftool.org/)で：コマンドライン（Windows のコマンドプロンプト、Mac/Linux のターミナル）を開いて、以下のコマンドを実行すると、画像内のすべての EXIF 情報が削除され、新しいファイルとして保存されます。
> ```bash
> exiftool -all= -o new_image.jpg image.jpg
> ```
> 3. オンラインツールで：EXIF 情報を削除できるオンラインツールのサイトを開き、処理したい画像をアップロードします。サイト側で EXIF 情報が削除されたら、処理後の画像をダウンロードしてください。（セキュリティ面が気になる場合は、他の方法をご利用ください）
>
>*（リポジトリのワークフローに画像の EXIF を削除する機能が組み込まれています。PR のコメント欄で `/auto-fix` コマンドを使って EXIF を削除することができます）*

### ファイルのサイズにご注意

GitHub のリソースを過度に消費しないため、サイズが `1MB` を超えている場合は、画像を圧縮してからアップロードしてください。

圧縮方法はこちら：

> **オンラインツールで：** 好きな画像圧縮のオンラインツールを開いて、処理したい画像ファイルをアップロードします。サイト側で自動的に処理されるので、処理後の画像をダウンロードしてください。（セキュリティ面が気になる場合は、他の方法をご利用ください）
>
>*（リポジトリのワークフローに画像を圧縮する機能が組み込まれています。 PR のコメント欄で `/auto-fix` コマンドを使って画像を圧縮することもできます。）*
