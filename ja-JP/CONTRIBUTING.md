### プライバシーにご注意

写真には EXIF データが含まれていることがあり、撮影場所や撮影機材などの情報が記録されています。意図しない個人情報の漏えいに注意し、写真を push する前に写真内の EXIF 情報を削除してください。

本プロジェクトは GPS・住所・連絡先などの高感度メタデータを自動的にブロックします。具体的なフィールド範囲と感度レベルは [EXIF](EXIF.md) をご覧ください。

削除方法はこちら：

> 1、[GIMP](https://www.gimp.org/downloads/)で：GIMP を開いて、処理したい画像を読み込みます。「ファイル」>「名前を付けて保存」を選び、JPEG などの形式を選択してください。表示される「画像の保存」ウィンドウで「詳細オプション」をクリックし、「EXIF データを保存」のチェックを外します。最後に「保存」をクリックすると、画像が保存され、EXIF 情報は削除されます。
> 
> 2、[ExifTool](https://exiftool.org/)で：コマンドライン（Windows のコマンドプロンプト、Mac/Linux のターミナル）を開いて、以下のコマンドを実行すると、画像内のすべての EXIF 情報が削除され、新しいファイルとして保存されます。
> ```bash
> exiftool -all= -o new_image.jpg image.jpg
> ```

>*（画像の EXIF 情報が依然として削除できない場合は、PR のマージ時にリポジトリの `/auto-fix` コマンドで EXIF 情報を削除できます）*

### ファイルのサイズにご注意

GitHub のリソースを過度に消費しないため、サイズが `1MB` を超えている場合は、画像を圧縮してから、アップロードしてください。

圧縮方法はこちら：

> **オンラインツールで：** 画像圧縮のオンラインツールを任意で1つ開いて、処理したい画像ファイルをアップロードします。サイト側で自動的に処理されるので、処理後の画像をダウンロードしてください。（セキュリティ面が気になる場合は、他の方法をご利用くださ）
>
>*（画像サイズが依然として `1MB` を超えている場合は、PR のコメント欄で `/auto-fix` を送信すると、画像を圧縮できます）*
